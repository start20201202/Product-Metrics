# Product-Metrics

1. Acquisition (Залучення)
Показує, як і звідки користувачі дізнаються про ваш продукт і скільки коштує їх привабити.
   Traffic / Users (Traffic volume): Кількість унікальних відвідувачів (Unique Visitors) за день (DAU), тиждень (WAU) або місяць (MAU).
   CAC (Customer Acquisition Cost): Вартість залучення одного платячого користувача. Розраховується як: $\text{CAC} = \frac{\text{Усі маркетингові витрати}}{\text{Кількість залучених клієнтів}}$.
   Sign-up Rate (або Conversion to Registration): Відсоток відвідувачів сайту/додатка, які створили акаунт чи залишили контакти.

2. Activation (Активація)
Етап, коли користувач вперше розуміє цінність продукту (так званий «Aha! Moment»). Якщо активація налаштована погано, більшість залучених користувачів піде назавжди.
   Activation Rate: Відсоток користувачів, які виконали ключову дію (наприклад, завантажили перший трек у Spotify, додали 5 друзів у соцмережі або створили перший документ у Notion).
   Time to Aha! (TTA): Час, який минає від моменту першого входу в додаток до моменту, коли користувач відчув першу користь від продукту.

3. Retention (Утримання)
Найважливіший блок метрик для здоров'я продукту. Без утримання ваш додаток перетвориться на «діряве відро»: скільки б маркетингового бюджету ви не вливали на етапі залучення, користувачі все одно йтимуть.
   Retention Rate (RR): Відсоток користувачів, які повертаються в продукт через певний час (N-й день, тиждень, місяць) після першого візиту.
   Churn Rate (Коефіцієнт відтоку): Відсоток користувачів, які перестали користуватися продуктом або скасували підписку за певний період. Розраховується як: $\text{Churn} = 100\% - \text{Retention}$.
   Stickiness (Липкість продукту): Показує регулярність використання продукту. Формула: $\text{Stickiness} = \frac{\text{DAU}}{\text{MAU}} \times 100\%$. Якщо показник вище 20%, продукт вважається дуже залучаючим.

4. Referral (Вірусність / Рекомендації)
Показує, наскільки користувачі готові ділитися вашим продуктом з іншими, що забезпечує органічне (безкоштовне) зростання.
   NPS (Net Promoter Score): Індекс лояльності. Користувачів запитують: «Оцініть від 0 до 10 ймовірність того, що ви порекомендуєте нас друзям».9–10: Промоутери (фанати).7–8: Скептики (нейтральні).0–6: Критики (незадоволені).$\text{NPS} = \% \text{Промоутерів} - \% \text{Критиків}$.
   K-Factor (Вірусний коефіцієнт): Скільки нових користувачів приводить один чинний клієнт. Якщо $K > 1$, продукт росте сам по собі за рахунок «сарафанного радіо».

7. Revenue (Монетизація)Показники, які демонструють фінансову ефективність продукту та його здатність заробляти.
   LTV (Lifetime Value / CLV): Загальна кількість грошей, яку один користувач приносить продукту за весь час використання. Критично важливо, щоб $LTV$ перевищував $CAC$ щонайменше у 3 рази.
   ARPU (Average Revenue Per User): Середній дохід від одного активного користувача за період (місяць/рік).
   ARPPU (Average Revenue Per Paying User): Середній дохід від одного платячого користувача (виключає тих, хто сидить на безкоштовному тарифі).
   MRR / ARR (Monthly / Annual Recurring Revenue): Щомісячний або щорічний регулярний дохід. Ключова метрика для SaaS-продуктів та моделей за підпискою.
